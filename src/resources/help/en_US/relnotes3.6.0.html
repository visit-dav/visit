General features added in version 3.6

  • OBJ export turns colors on by default.
  • OBJ export has additional choices for setting color attributes.
  • Support for tiled rendering has been added to VisIt, which allows for rendering images of an arbitrarily large size. Tiled rendering is always enabled with a default tile width and height of 2048. The image tile size can be set to a maximum image tile width and height of 8192.

Changes to VisIt's plots in version 3.6

  • Issues with the Label plot when zooming/panning, and having labels drawn internal to a mesh were fixed.
  • Spreadsheet plot data visibility and tracer plane functionality has been fixed.

Changes to VisIt's operators in version 3.6

  • The Connected Components Operator, when used improperly, provides more information to users about how to properly apply it.
  • Operator Change 2

Changes to VisIt's expression language in version 3.6

  • The conn_components() expression now includes quickfill hints for its arguments.
  • The conn_components() expression now correctly takes 0 or 1 for the enable ghost-neighbor optimization argument instead of also mistakenly taking 2.

Other bugs fixed in version 3.6

  • An issue partitioning nodal coordinates for parallel in Pixie files was fixed.
  • Fixed bug with thirdparty Find mdoules when thirdparty library was not built in 'Release' mode.

Changes to build_visit in version 3.6

  • build_visit now has a `--cleanup` option. When turned on it triggers deletion of src and build dirs for each library if build and install are successful.
  • MOAB was updated to version 5.6.0.
  • The `--print-files` and `--print-files-html` options were fixed so that no libraries are missing from the printed lists.

Changes for VisIt developers in version 3.6

  • Enhanced multi_test.C data generator to handle both single and double precision.
