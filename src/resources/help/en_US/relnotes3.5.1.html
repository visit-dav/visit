VisIt 3.5.1 Release Notes

Welcome to VisIt's release notes page. This page describes the important enhancements and bug-fixes that were added to this release.

Sections

  • Bug Fixes
  • Enhancements
  • Changes for VisIt developers

Bugs fixed in version 3.5.1

  • Fixed a bug where slicing or contouring an unstructured mesh with VTK_CONVEX_POINT_SET cells caused a crash.
  • Fixed a bug with Zone-Pick on an extremely zoomed-in plot containing extremely long thin hexes.

Enhancements in version 3.5.1

  • CGNS reader was enhanced to handle SIDS-style time-varying data.
  • The visit-install scripts now accepts '-f' argument allowing specification of the distribution filename in lieu of using the 'version' and 'platform' positional arguments.

Changes for VisIt developers in version 3.5.1

  • CMake usage within VisIt has been modernized. VisIt now installs an export set so that VisIt can be 'imported' by other projects. Only use case tested was building a plugin against an installed VisIt. Documentation related to CMake conventions was updated.
  • Default file locking for HDF5 when built with build_visit is now set to disabled.
  • As a precaution against default HDF5 file locking behavior (ON/TRUE), if it is not already set in the environment when VisIt is launched, the HDF5_USE_FILE_LOCKING environment variable is set to FALSE in internallauncher.
